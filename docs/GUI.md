# PySide6 控制面板（v0.6.0）

中文原生 Qt 桌面界面，暖白 / 陶土橙配色，采用 Claude Code 的 Clawd 像素形象。Qt 在本地绘制其经典终端外形，并提供眨眼、轻微浮动和状态标记；角色归属见 [NOTICE](../NOTICE.md)。不是 Anthropic 官方产品。

界面提供工作台、连接配置、诊断与日志、环境检测、使用指南。系统服务与 CLI 不依赖 Qt；安装图形依赖不会改变内核策略。

## 在 Ubuntu 首次打开

下载并解压 `claude-protect-0.6.0-ubuntu.tar.gz`，进入解压目录，在普通桌面用户终端执行：

```bash
sudo apt update
sudo apt install python3-venv libxcb-cursor0 libegl1 libxkbcommon-x11-0
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements-gui.txt
.venv/bin/python scripts/gui.py
```

不使用 `sudo pip`，不以 root 身份运行面板。Qt 官方建议在虚拟环境安装 PySide6；wheel 自带 Qt 库，无需另外安装 Qt Creator：
<https://doc.qt.io/qtforpython-6/gettingstarted.html>。

若提示 Qt 平台插件无法加载，请确认上面的 Ubuntu 库安装成功；不要通过关闭 Chromium sandbox 解决。

面板在系统组件尚未安装时也能打开。先安装官方 .deb 版 VS Code / Google Chrome，再按界面操作：

1. 进入「连接配置」，确认发行包目录与桌面用户。
2. 点击「检查 / 安装系统依赖」，在弹出的系统终端完成 apt 安装；按终端结果确认成功后继续。
3. 选择受控模式或兼容模式，填写实际代理参数。兼容模式需先启动自己的 HTTP / 混合代理。
4. 点击「在终端中安装系统组件」，在系统终端中输入管理员密码；选中代理认证时还会在该终端输入代理用户名和密码。命令结束后会保留结果，按 Enter 再关闭终端。
5. 终端安装成功后点击「刷新状态」。隔离服务核对通过后，分别安装状态插件与官方 Claude Code 插件。
6. 在「工作台」选择项目，打开 VS Code；日常网页版使用「打开 Claude 网页」。本人在专用窗口完成 Claude 登录。
7. 「使用指南 → 添加面板到应用菜单」创建普通用户的快捷方式。保留解压目录和 `.venv`，以后可从应用菜单启动。

应用菜单与窗口使用 `lib/claude_protect/assets/claude-protect.png` 图标，透明圆角已处理。
同目录的 SVG 保留原图并定义精确圆角裁切，PNG 为其导出版本。

若没有默认密钥链，或密钥链处于锁定状态，启动器会拒绝打开应用。在 Ubuntu 的密码 / 密钥管理器中创建并解锁默认密钥链后重试。面板的密钥链按钮会显式启动过滤用户服务，再进行预检。

## 状态如何解读

- 连接配置：顶部显示组件安装与隔离核对结果；刷新时读取实际模式及端口，已安装配置以只读方式展示。依赖已检测到时无需重复安装。
- 插件安装：分别核对专用窗口的插件清单与实际版本文件，显示已安装版本。此状态说明插件已安装，运行状态需在受保护 VS Code 窗口中查看。
- 隔离服务：读取现有 root 状态服务，与命名空间、路由和出站规则核对结果一致。
- 上游出口：区分固定 TLS 上游、外部代理和测试配置。外部模式显示「尚未检测 / 已自动检测 / 发现问题」及各类结果数量，不会将检测结果当作上游已受控。
- 密钥链：仅显示上次通道预检；浏览器实际后端、磁盘加密仍未证明。
- 联网验证：仅显示上次主动测试结果与时间，不持续探测，不代表账号安全。

面板本身在普通桌面。它读取的 `session_isolated=false` 属于预期，不能据此把专用窗口也判为失败，也不会把面板自己标为已隔离。VS Code 与浏览器入口仍经过原来的内核、权限、profile 和密钥链检查。

状态每 15 秒只读刷新；发现策略变化或状态读取失败，会清除此前联网与密钥链结果。实际网络变化还需重新主动验证。关闭面板不会关闭它启动的工作窗口，不会关闭防护服务。

## 检测外部代理

在「工作台」或「诊断与日志」点击「检测外部代理」；一键环境检测也会调用同一检查。面板异步运行检测并显示五行结果及 UTC 时间：

- 代理识别：读取 Clash Verge 标准 Unix 控制接口，核对端口、模式和 TUN 开关；需要控制密码或其他接口路径时保留为未验证，不尝试获取密码。
- Claude 测试连接：从面板连接外部代理端口，为 claude.ai 建立匿名 TLS 连接，并按源端口匹配核心连接列表，检查是否 DIRECT。不读取已登录浏览器或扩展的请求，不将此样本当作全部应用的流量证明。
- DNS 配置：自动调用核心 DNS 查询并读取配置；无权限时明确标注用户侧配置快照。点击「授权读取 DNS 运行配置」，在系统终端输入本机管理员密码后，软件只读固定运行配置并保存布尔结果到 root 管理的 `/run/claude-protect/dns-observation.json`，关闭终端后自动重测。只分析简单 DNS YAML 字段；复杂语法不推断为已配置，查询成功不当作抓包证明。
- 隔离内出口：复用已有固定诊断入口，在隔离内两次访问 ipify；失败不回退到主机直连。
- 自动回退配置：在全局模式下遍历当前选中链及 Fallback / URLTest / LoadBalance 自动分支，检查能否选择 DIRECT；手动选择器中未选中的 DIRECT 不算自动回退。未知策略保留未验证。此项通过只代表配置检查，仍不等于中断上游后的故障注入测试。

结果有效期 10 分钟；隔离策略变化、超时、失败或检测期间代理模式/节点变化会清除成功结果。检测完成后再切换节点需要主动重测。导出报告包含项目状态并隐藏 IP 尾段，不包含节点名称、控制密码或原始配置。现有系统组件支持 `egress` 即可使用新版源码面板，无需为此重装系统服务。

同一次外部代理检查取得的出口结果会同步到「实际出口与变化」、环境检测清单及本机历史，无需重复点击出口检测；该按钮也会更新离线宿主环境检查。DNS 提示会区分查询接口超时、核心报告解析超时、DNS 错误码和无有效地址，不把查询未完成等同于泄露。运行配置的路由遵从、节点解析器与核心 DNS 查询均通过时，仅标记 DNS 配置/解析检查通过，仍不代替抓包验证。

v0.4 在「诊断与日志」增加五项核心保护的验收进度、主动出口观测与本机历史、离线环境检查、约 20 秒滴流 / 连接复用样本、脱敏报告和受保护第三方对照页面。
出口与滴流只在点击按钮时联网；策略变化后会丢弃或清除相关结果。离线环境自检不会读取运行中的 Claude 或项目设置。
历史仅本机保存，最多 30 条，包含完整出口 IP；默认隐藏 IP 尾段，导出始终脱敏，但网络前缀仍可能识别网络。详见 [网络诊断](NETWORK_DIAGNOSTICS.md)。

v0.5 增加「环境检测」：一键按顺序运行自检，按证据显示通过 / 需要处理 / 需要核对 / 尚未验证，并给出配置、密钥链、重测和受保护 Net.Coffee 入口。工作台同步显示待处理提醒。
本机状态超过 45 秒、其他自检超过 10 分钟会要求重测，不新增后台联网任务；浏览器 / IP 信誉不冒充已自动验证。详见 [环境检测与设置提醒](ENVIRONMENT_CHECK.md)。

本次会话日志仅在面板内存中保存，限量保留；可以主动复制。管理员与代理密码由系统终端读取，不经过图形界面、进程参数或面板日志。面板不读取 Claude Token / Cookie，不提供账号密码输入框。

## 预览界面

macOS / Ubuntu 都可以在已安装 PySide6 的环境中运行：

```bash
python scripts/gui.py --demo
```

演示模式显式显示「未连接系统」，禁用系统操作，不虚构网络检查成功。预览不等于 Ubuntu 运行验收。

系统安装后也可通过安装有 PySide6 的 Python 解释器打开面板：

```bash
/你的/虚拟环境/bin/python /usr/local/bin/claude-protect gui
```

`claude-protect` 默认使用系统 Python；若 PySide6 仅在虚拟环境中，直接运行 `claude-protect gui` 会提示缺少依赖，应使用上面的显式解释器或应用菜单快捷方式。

## 卸载与修改配置

关闭所有受保护应用并等待检测结束后，在「连接配置」顶部或「使用指南」点击「还原系统配置」，终端确认成功后可修改代理配置并重新安装。GUI 不提供临时关闭防火墙或回退直连按钮。

v0.6 的还原操作使用现有卸载路径，并在删除剩余配置前核对专用 namespace、接口、上游表和系统服务状态。清理失败保留归属记录供检查；不会清空主机其他规则。新安装会保存 root 管理的卸载脚本，减少对解压目录的依赖。详见 [还原与网速说明](RESTORE.md)。

系统卸载保留用户数据、发行包和面板环境。若也不再需要面板，删除其解压目录、虚拟环境，以及：

```text
~/.local/share/applications/claude-protect-panel.desktop
```
