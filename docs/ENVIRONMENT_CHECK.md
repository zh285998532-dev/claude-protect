# 环境检测与设置提醒（v0.5.0）

这是一份本机检查清单，借鉴用户提供的 Net.Coffee 检测页的组织方式，将现有检测结果与具体设置建议连接起来。不是 Anthropic 官方评分，也不计算封号概率。

## 使用流程

1. 打开面板的「环境检测」。
2. 点击「开始检测（含联网）」。默认包括约 20 秒流式样本，可以在开始前取消勾选。
3. 面板先做离线环境检查，再依次核对隔离状态、密钥链通道、DNS / IPv6 / 代理连通性、实际出口、外部代理，以及可选的流式样本。受控上游跳过外部代理检测。
4. 查看「需要处理 / 需要核对 / 尚未验证 / 本次通过」和对应设置入口。
5. 点击「打开 Net.Coffee 对照检测」，在受保护 Chrome 中继续检查浏览器 DNS、WebRTC、环境及 IP 属性。其分数不会自动导入面板。
6. 设置完成后重新检测，需要时导出脱敏报告；报告附带本次清单与设置建议。

联网步骤主动访问 example.com、ipify、httpbin；外部代理检测还会经本机代理端口与 claude.ai 建立匿名 TLS 测试连接。不会登录 Claude、读取账号凭据或发送代码，不自动改代理、语言、时区，也不自动购买或更换出口。

## 逐项检查

| 项目 | 自动依据 | 可能的设置提醒 |
|---|---|---|
| 配套组件与隔离 | 配置存在、最近内核核对 | 安装组件、刷新状态、查看诊断日志 |
| 代理自身 DNS / 出口 | 模式、外部代理主动检测结果及时间 | 自动核对测试连接、DIRECT 自动分支、DNS 查询/配置和隔离内出口；运行配置无读取权限时提供只读管理员授权入口 |
| 应用侧 DNS 防旁路 | 当前策略下的 DNS 阻断探测和 HTTPS 正向对照 | 检查代理与端口，重测；抓包另行验收 |
| 隔离内 IPv6 约束 | 当前策略下 IPv6 直连阻断探测 | 重测，不要求关闭主机全局 IPv6 |
| 连通与直连阻断 | 正向 TLS、直连阻断、前后运行时核对 | 检查代理、TLS 与诊断日志 |
| 桌面密钥链通道 | 过滤服务、默认 collection 解锁状态 | 打开 Ubuntu「密码和密钥」，创建并解锁后重测 |
| 实际出口与变化 | 两次 ipify 请求、同策略历史比较 | 核对供应商轮换和按目标分流，先查原因，不自动切换节点 |
| 流式通道 | 约 20 秒通用滴流样本 | 检查缓冲、代理或检测服务；真实 Claude 会话仍待验收 |
| 宿主进程配置 | 白名单环境变量 | 到诊断页查看冲突、旁路或 API / TLS 提示 |
| 浏览器 DNS / WebRTC / 环境 | 尚未自动取得浏览器实测数据 | 用受保护 Net.Coffee 页面核对，Qt 面板不能替代 Chrome |
| IP 地区 / ASN / 信誉 | 未接入信誉数据源、未核实使用资格 | 第三方数据作参考，并自行核对官方支持地区 |

点击设置建议只跳转到对应页面、发起列出的检查，或打开密码管理器。安装 / 卸载仍经既有系统终端进行，需要用户在终端完成管理员授权。

## 提醒与结果有效期

- 工作台显示当前待处理、待核对和未验证项数量。提醒只存在于面板内，不创建系统定时任务或云端监控。
- 在线探测、密钥链预检和离线环境检查需在最近 10 分钟内，过期即回到待验证。
- 隔离状态需在最近 45 秒内，沿用面板每 15 秒的本机只读刷新。状态变化会清除有关探测结果。
- 未执行、缺少正向对照、结果过期或隔离未就绪时，不显示绿色。
- 外部代理的五项检查均在有效期内通过时，工作台卡片显示绿色「本次通过」，清单同步通过；这仍是配置与抽样结果，不代表软件已强制约束外部代理。
- 基础联网未通过时，跳过后续出口 / 流式请求，先提示检查代理。
- 「停止后续步骤」会等待当前有时限的检查结束后停止；关闭面板不会继续启动后续步骤，也不关闭已启动的 VS Code / 浏览器。
- 当其他按钮已启动同一检查时，一键流程等待其完成再继续，避免重复发起同类请求。

密钥链和短请求检查时间使用带时区的时间戳；不把没有时区、明显未来或格式错误的时间戳当作有效结果。

## 与 Net.Coffee 的区别和边界

原站还展示地区、ASN、住宅 / 机房、代理 / Tor / 滥用标记、WebRTC、Canvas 与 WebGL 等浏览器信息。本面板没有假装已经取得这些数据，也不将网页初始占位内容当作你的检测结果。

Net.Coffee 始终通过现有受保护浏览器启动器打开。不会在宿主 Qt 面板内嵌入网页来测出错误的宿主出口，也不嵌入第三方脚本。网站会收到访问 IP；网站所见出口不保证等于 Anthropic 所见出口。

浏览器和信誉两项保留为未自动验证。因此即便现有技术检查都通过，清单仍不会宣称“账号安全”或“全部验收完成”。中文、时区或字体不作为账号违规判据。

## 版本与验收

已有 v0.4 系统组件兼容本页所用的诊断命令。只预览 / 使用解压目录中的新版面板可保留现有系统策略；若升级已安装的整套系统组件，仍按安装说明先关闭受保护应用、卸载旧版，再安装新版。

macOS 仅预览：

```bash
python3 scripts/gui.py --demo
```

演示模式所有项目都显示未验证，不执行检查或修改菜单。Ubuntu 实机、真实代理与浏览器数据仍需后续验收；本轮验证的是规则、流程和 Qt 交互。
